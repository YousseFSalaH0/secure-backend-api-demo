# Secure Backend API Demo

> Dependency-free Node.js API demonstrating authentication, validation, security headers and idempotent webhooks.

![Service preview](preview.png)

## Included
- Public health endpoint and protected customer endpoint
- Bearer authentication and input validation
- Structured error contracts and secure response headers
- Idempotent webhook processing
- Automated tests using Node's built-in test runner

## Run
`npm test`, then `npm start`.

## Portfolio notice
Original service demo; no client source, credentials or production data.
